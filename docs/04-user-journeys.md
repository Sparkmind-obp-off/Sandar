# 04 — Core User Journeys

## Journey A: Start privately
1. Open SANDAR without creating a public profile.
2. Read a short explanation of what the product does and does not do.
3. Choose a module and a goal.
4. Enter only the minimum information needed for that goal.
5. Review the generated summary and correct assumptions.
6. Save locally or to a private account only after the storage model is clear.

Acceptance: no forced sensitive onboarding, no public profile, and no personal-data collection before a feature needs it.

## Journey B: Plan a tight month
1. User enters expected income, known bills, and dates.
2. SANDAR displays the arithmetic and highlights gaps or uncertainty.
3. User chooses which items to prioritize.
4. SANDAR offers a few options and explains trade-offs.
5. User edits the plan and exports or saves it.

Acceptance: no shame language, no automatic payment decisions, and no unsupported financial advice.

## Journey C: Find a public resource
1. User selects a service topic and jurisdiction.
2. SANDAR searches its curated public-resource catalogue.
3. Each result shows issuer, source link, coverage, last checked, and known caveats.
4. User opens the official source to verify details.
5. User may save the link privately.

Acceptance: SANDAR never declares eligibility unless the official authority itself provides an unambiguous result, and even then links to that authority.

## Journey D: Explore an opportunity
1. User chooses a goal or skill they want to develop.
2. SANDAR shows public opportunities with dates, costs, and prerequisites where verified.
3. User compares options and builds a preparation checklist.
4. User chooses whether to visit the publisher's application page.

Acceptance: no application is submitted by SANDAR in the MVP.

## Journey E: Shared household planning
1. One user creates a specific shared goal.
2. They invite another adult with a clear explanation of what will be shared.
3. The invitee explicitly accepts.
4. Each participant chooses what to contribute.
5. Either participant can leave the shared space and review what happens to shared data.

Acceptance: no shared view exists before acceptance; private data remains private.

## Journey F: Pause or leave
1. User can pause reminders and recommendations.
2. User can export or delete their workspace data.
3. The product explains any retention or deletion limitations before confirmation.

Acceptance: no dark patterns, guilt prompts, or hidden retention.
