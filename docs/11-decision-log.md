# 11 — Decision Log

**Decision:** SANDAR is the working and primary project name.
**Status:** Locked as project naming direction; trademark clearance is not claimed.
**Context:** Owner selected SANDAR after preliminary PDKI checks. PENDAR remains a retained fallback candidate, not the active project name.

## D-002 — Product category
**Decision:** Life Navigation & Resilience OS.
**Status:** Accepted.
**Meaning:** An agentic life-navigation engine with a lightweight web/PWA interface; not a native computer OS.

## D-003 — Privacy model
**Decision:** Private-first, voluntary user data, no inference about non-consenting people.
**Status:** Hard constraint.

**Status:** Foundation scope; module details may evolve after validation.

**Status:** Hard constraint unless the owner explicitly approves a specific expense.
