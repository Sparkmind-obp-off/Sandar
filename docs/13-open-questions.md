# 13 — Open Questions

These questions must be resolved before moving from documentation into implementation.

## Product
- Which user problem will be the first validated entry point: near-term cash-flow planning or public-resource navigation?
- What is the smallest useful outcome a first-time user can complete in under ten minutes?
- Which features must work without an account?

## Indonesia-specific resource data
- Which official national and local portals provide stable, reusable public information?
- Which fields are legally and operationally safe to republish with attribution?
- How will stale, withdrawn, or conflicting information be handled?

## Privacy and legal
- Which legal entity will operate SANDAR?
- What personal-data controller/processor roles apply to the actual architecture?
- What retention period is necessary for each data class?
- Which legal reviews are needed before a controlled pilot?

## Technical
- Is the first release fully local/private or account-based?
- Which database and hosting combination meets the Rp0 constraint at expected scale?
- How will backups be encrypted and restored?
- Which AI tasks can be deterministic or performed locally to avoid sending user data externally?

## Validation
- Which opt-in research participants can test synthetic scenarios first?
- What usability measures indicate that the next step became clearer?
- How will feedback be collected without collecting unnecessary sensitive information?

## Domain and brand
- Confirm registrar ownership, DNS access, and renewal state for `sandar.biz.id`.
- Complete class-specific trademark review; current repository status is not legal clearance.
